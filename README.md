# Kilobat downloads

Official signed and Apple-notarized macOS releases of [Kilobat](https://kilobat.app).

Download the DMG from Releases, open it, and drag Kilobat into Applications. Requires macOS 14 or later; supports Apple silicon and Intel Macs.

The Mac app is free to download. Kilobat Pro is a one-time $19 purchase for two Macs. See the website for terms and support.

The bundled CLI is GPL-3.0-only. Its source is available at https://github.com/seifip/kilobat-cli. The desktop app is distributed under its own terms.
